# Улучшения взаимодействия между вкладками

## Реализованные улучшения

### 1. Единый контекст приложения (AppContext)

**Проблема:** Каждая страница загружала данные отдельно, что приводило к дублированию кода и несогласованности данных.

**Решение:** Создан глобальный контекст `AppContext`, который:
- Централизует загрузку и хранение данных о товарах
- Предоставляет единый API для работы с данными
- Автоматически обновляет данные при изменениях
- Управляет категориями товаров

**Использование:**
```typescript
import { useApp } from "@/contexts/AppContext";

const { items, categories, refreshItems, getItemById } = useApp();
```

### 2. Улучшенная навигация с параметрами

**Возможности:**
- Переход к конкретному товару: `/edit?itemId=123`
- Переход к конфигурации: `/configurations?configId=456`
- Переход к документам товара: `/documents?itemId=123`
- Автоматический выбор элемента при загрузке страницы

**Примеры:**
```typescript
// Из контекста
navigateToEdit(123);        // Переход к редактированию товара #123
navigateToItem(123);        // Переход к главной странице и выбор товара #123
navigateToDocuments(123);  // Переход к документам товара #123
```

### 3. Быстрые ссылки на товары (ItemLink)

**Компонент:** `ItemLink` - кликабельная ссылка на товар

**Использование:**
- В списках конфигураций - переход к товару
- В документах - переход к связанным товарам
- В статистике - переход к товарам из отчетов
- В любом месте, где упоминается товар

**Пример:**
```tsx
<ItemLink itemId={123} itemName="SSD 1TB" variant="ghost" size="sm" />
```

### 4. Компонент быстрых действий (QuickActions)

**Компонент:** `QuickActions` - выпадающее меню с действиями для товара

**Действия:**
- Просмотреть товар (переход на главную)
- Редактировать (переход на страницу редактирования)
- Документы (переход к документам товара)

### 5. Унифицированная обработка обновлений

**События:**
- `componentsUpdated` - обновление товаров
- `configurationsUpdated` - обновление конфигураций
- `documentsUpdated` - обновление документов

**Автоматическая синхронизация:**
- Все страницы автоматически обновляются при изменениях
- Контекст слушает события и обновляет данные
- Нет необходимости вручную обновлять каждую страницу

## Логика работы вкладок

### Главная вкладка (Index) - "Склад"
**Назначение:** Просмотр, поиск и быстрый просмотр товаров
**Функции:**
- Поиск по названию, категории, расположению, штрихкоду
- Фильтрация по категориям
- Выбор товара для просмотра деталей
- Добавление товаров (через диалог)
- Сканирование штрихкодов

### Вкладка "Добавить"
**Назначение:** Быстрое добавление нового товара
**Функции:**
- Открывает диалог добавления на главной странице
- Если на другой странице - переходит на главную и открывает диалог
- Поддержка всех полей, включая штрихкод

### Вкладка "Изменить" (Edit)
**Назначение:** Редактирование товаров и списание
**Функции:**
- Список всех товаров с возможностью редактирования
- Редактирование через диалог
- Списание товаров с указанием склада
- Автоматическое создание записей о списании
- Поддержка URL параметра `?itemId=123` для прямого редактирования

### Вкладка "Статистика" (Calculator)
**Назначение:** Анализ и расчеты
**Функции:**
- Расчет доступности конфигураций
- Статистика склада
- Планирование закупок
- Ручной расчет стоимости
- Экспорт отчетов
- Ссылки на товары из всех списков

### Вкладка "Конфигурации" (Configurations)
**Назначение:** Создание и управление конфигурациями
**Функции:**
- Создание конфигураций из товаров
- Просмотр доступности компонентов
- Расчет стоимости конфигураций
- Ссылки на товары в составе конфигураций
- Поддержка URL параметра `?configId=456`

### Вкладка "Документы" (Documents)
**Назначение:** Управление документами товаров
**Функции:**
- Загрузка документов
- Привязка к товарам
- Просмотр и скачивание
- Фильтрация по товарам
- Ссылки на связанные товары
- Поддержка URL параметра `?itemId=123` для фильтрации

### Вкладка "Настройки" (Settings)
**Назначение:** Управление системой и базой данных
**Функции:**
- Управление БД (резервные копии, экспорт/импорт)
- Настройки пула соединений
- Управление кэшем
- Изменение местоположения БД
- Настройка внешних баз данных

## Улучшения навигации

### Переходы между связанными элементами

1. **Из конфигурации к товару:**
   - Клик на название товара → переход на главную с выбором товара

2. **Из документа к товару:**
   - Клик на название товара → переход на главную с выбором товара

3. **Из статистики к товару:**
   - Клик на название товара → переход на главную с выбором товара

4. **Из любого места к редактированию:**
   - Использование `navigateToEdit(itemId)` → переход на страницу редактирования

5. **Из любого места к документам:**
   - Использование `navigateToDocuments(itemId)` → переход к документам с фильтром

## Преимущества новой архитектуры

1. **Единый источник данных** - все данные загружаются один раз
2. **Автоматическая синхронизация** - изменения отражаются везде
3. **Улучшенная навигация** - быстрые переходы между связанными элементами
4. **Меньше дублирования кода** - общая логика в контексте
5. **Лучшая производительность** - данные кэшируются в контексте
6. **Проще тестирование** - четкое разделение ответственности

## Примеры использования

### Получение товара по ID
```typescript
const { getItemById } = useApp();
const item = getItemById(123);
```

### Получение товара по штрихкоду
```typescript
const { getItemByBarcode } = useApp();
const item = getItemByBarcode("1234567890123");
```

### Переход к товару
```typescript
const { navigateToItem } = useApp();
navigateToItem(123); // Переходит на главную и выбирает товар
```

### Обновление данных
```typescript
const { refreshItems } = useApp();
await refreshItems(); // Перезагружает все товары
```

## События для синхронизации

Все страницы автоматически обновляются при следующих событиях:

- `componentsUpdated` - при изменении товаров
- `configurationsUpdated` - при изменении конфигураций  
- `documentsUpdated` - при изменении документов

События автоматически обрабатываются контекстом и обновляют данные.
