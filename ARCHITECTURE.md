# Архитектура проекта склада

## Обзор

Проект представляет собой десктопное приложение для управления складом, построенное на Tauri (Rust + React/TypeScript).

## Структура проекта

```
src/
├── components/          # React компоненты
│   ├── inventory/      # Компоненты для работы с инвентарем
│   ├── layout/         # Компоненты макета
│   ├── ui/            # UI компоненты (shadcn/ui)
│   └── ...
├── services/          # Сервисный слой (бизнес-логика)
│   ├── inventoryService.ts
│   └── errorHandler.ts
├── lib/               # Утилиты и работа с БД
│   ├── db.ts         # Основные функции работы с БД
│   ├── db-pool.ts    # Пул соединений
│   ├── db-cache.ts   # Кэширование
│   └── ...
├── pages/            # Страницы приложения
└── hooks/            # React хуки
```

## Слои архитектуры

### 1. Presentation Layer (Компоненты)
- **Назначение**: Отображение UI и обработка пользовательских действий
- **Расположение**: `src/components/`, `src/pages/`
- **Ответственность**:
  - Отображение данных
  - Обработка пользовательского ввода
  - Вызов сервисов для выполнения операций

### 2. Service Layer (Сервисы)
- **Назначение**: Бизнес-логика и координация операций
- **Расположение**: `src/services/`
- **Ответственность**:
  - Инкапсуляция бизнес-логики
  - Координация нескольких операций БД
  - Валидация бизнес-правил

**Примеры сервисов:**
- `inventoryService.ts` - работа с инвентарем
- `errorHandler.ts` - централизованная обработка ошибок

### 3. Data Access Layer (БД)
- **Назначение**: Работа с базой данных
- **Расположение**: `src/lib/db*.ts`
- **Ответственность**:
  - CRUD операции
  - Управление соединениями (пул)
  - Кэширование
  - Транзакции

## Основные улучшения

### 1. Исправлена проблема с черным экраном

**Проблема**: При открытии описания этапа товара экран становился черным.

**Решение**:
- Добавлена валидация данных перед отображением
- Добавлена обработка ошибок при загрузке данных
- Добавлена проверка типов этапов (включая 'processing' и 'storage')
- Добавлены fallback значения для отсутствующих данных

**Файлы**: `src/components/inventory/LocationDistribution.tsx`

### 2. Исправлена вкладка "Изменить"

**Проблема**: При изменении количества товара не создавались записи о списании.

**Решение**:
- Создан сервис `inventoryService.ts` с функцией `updateItemWithScrapping`
- Автоматическое создание записей о списании при уменьшении количества
- Интеграция с системой групп складов
- Улучшенная обработка ошибок

**Файлы**: 
- `src/pages/Edit.tsx`
- `src/services/inventoryService.ts`

### 3. Улучшена обработка ошибок

**Улучшения**:
- Создан централизованный обработчик ошибок
- Понятные сообщения для пользователя
- Логирование ошибок с контекстом
- Обработка специфичных ошибок БД (блокировка, отсутствие таблиц и т.д.)

**Файлы**: `src/services/errorHandler.ts`

### 4. Реорганизация архитектуры

**Изменения**:
- Выделен сервисный слой для бизнес-логики
- Разделение ответственности между слоями
- Улучшена переиспользуемость кода
- Централизованная обработка ошибок

## Работа с БД

### Пул соединений
- Используется пул соединений для оптимизации
- Автоматическое управление жизненным циклом соединений

### Кэширование
- Кэширование результатов запросов
- Автоматическая инвалидация при изменениях
- Настраиваемое время жизни кэша

### Транзакции
- Использование транзакций для атомарных операций
- Автоматический rollback при ошибках

## Работа с ошибками

Все ошибки обрабатываются через `errorHandler.ts`:
- Автоматическое определение типа ошибки
- Понятные сообщения для пользователя
- Логирование для отладки

Пример использования:
```typescript
import { logAndFormatError } from "@/services/errorHandler";

try {
  // операция
} catch (error) {
  const message = logAndFormatError(error, 'контекст операции');
  alert(message);
}
```

## Миграции БД

Миграции выполняются автоматически при инициализации БД через `DatabaseMigration.checkAndMigrate()`.

## События

Приложение использует кастомные события для синхронизации состояния:
- `componentsUpdated` - обновление товаров
- `configurationsUpdated` - обновление конфигураций
- `documentsUpdated` - обновление документов
