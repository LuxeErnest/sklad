# Функциональность работы со штрихкодами

## Реализованные возможности

### 1. Поиск по штрихкоду в главной вкладке
- Поиск автоматически ищет по штрихкоду при вводе в поле поиска
- Штрихкод включен в общий поиск вместе с названием, категорией и расположением

### 2. Добавление штрихкода при создании товара
- В форме добавления товара есть поле "Штрихкод"
- Поле опциональное
- Поддерживается автозаполнение при вводе

### 3. Сканирование штрихкода
- **Кнопка сканирования** в верхней панели (иконка сканера)
- **Два режима сканирования:**
  - Камера: активация веб-камеры для сканирования
  - Ручной ввод: ввод штрихкода вручную

### 4. Глобальный поиск по штрихкоду
- Можно быстро ввести штрихкод с клавиатуры (когда фокус не в поле ввода)
- Система автоматически найдет товар и откроет диалог редактирования
- Работает из любого места приложения

### 5. Диалог редактирования при сканировании
- При успешном сканировании открывается диалог с информацией о товаре
- Возможность сразу отредактировать параметры товара
- Показывается штрихкод найденного товара

## Использование

### Сканирование через камеру:
1. Нажмите кнопку сканирования в верхней панели
2. Нажмите "Включить камеру"
3. Наведите камеру на штрихкод
4. Товар будет найден автоматически

### Ручной ввод:
1. Нажмите кнопку сканирования
2. Введите штрихкод в поле
3. Нажмите "Найти" или Enter

### Быстрый поиск (глобальный):
1. Убедитесь, что фокус не в поле ввода
2. Быстро введите штрихкод
3. Нажмите Enter
4. Товар будет найден и откроется диалог редактирования

## Технические детали

### База данных
- Поле `barcode` добавлено в таблицу `components`
- Автоматическая миграция при первом запуске
- Штрихкод хранится как TEXT (поддерживает любые форматы)

### Компоненты
- `BarcodeScanner` - компонент сканирования
- `BarcodeItemDialog` - диалог отображения найденного товара
- `useBarcodeScanner` - хук для работы со штрихкодами

### Поиск
- Поиск по штрихкоду работает в реальном времени
- Регистронезависимый поиск
- Поддержка частичного совпадения
